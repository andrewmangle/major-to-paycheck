# Major to Paycheck

An independent prototype for Bowie State College of Business students. Students pick a program and a place to
live (Baltimore, DC or Northern Virginia). The page shows the jobs that program leads to, early-career pay, what's
left after 2026 taxes and rent, and what gets them hired.

It's a single static page with no server and no tracking. `index.html` is the whole site.

## Put it on GitHub Pages

1. Create a new repository on GitHub, for example `major-to-paycheck`.
2. Push this folder to it:
   ```
   git remote add origin https://github.com/<your-account>/major-to-paycheck.git
   git push -u origin main
   ```
3. On GitHub, go to **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then
   **main** and **/ (root)**, and save.
4. After a minute the site is live at `https://<your-account>.github.io/major-to-paycheck/`.

Links can open a specific program and place, for example `.../#accounting-baltimore` or
`.../#business-information-systems-dc`. That's handy for sending students straight to their own view.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The built page. Generated by `build.py`, so don't edit it by hand. |
| `data.py` | Programs, roles, hiring advice, first-job paths, rents, tax rules and sources. Edit content here. |
| `template.html` | Page layout, styles and script. `build.py` puts the data into it. |
| `build.py` | `python3 build.py` rebuilds `index.html`. It needs only Python 3, no packages. |
| `bls_wages.json` | Pay pulled from the BLS file for every role. Generated by `load_bls.py`. |
| `load_bls.py` | Reads the BLS OEWS metro file into `bls_wages.json`. Needs `pip install -r requirements.txt`. |
| `tests/` | `python3 -m unittest discover -s tests` checks the build, tax math and first-job numbers. |

## Updating the data

The BLS spreadsheets are about 40 MB, so they aren't kept in git. To refresh wages when BLS publishes a new
release:

1. Download the metro area file from https://www.bls.gov/oes/tables.htm (the `oesmYYma.zip` file) and unzip it.
2. `python3 load_bls.py path/to/oesmYYma/MSA_MYYYY_dl.xlsx`
3. `python3 build.py`
4. `python3 -m unittest discover -s tests`, then commit and push.

## Where most people start

Some roles have a 25th-percentile pay that's well above what new grads earn (Cybersecurity Analyst, Data Analyst /
Data Scientist, Database Administrator). Their cards show a first-job line, for example *Where most people start:
IT support, $50,230 → this job after experience: $104,500*. The first-job number is the 25th percentile of the
stepping-stone job from the same BLS file. To add the line to another role, give it a `first_job` entry in
`data.py`.

## Sources

- **Wages:** BLS Occupational Employment and Wage Statistics, May 2025, for the Baltimore-Columbia-Towson and
  Washington-Arlington-Alexandria metro areas. Early-career pay is the 25th percentile. The Economist card uses
  the 2026 GS-7 rate for the Washington-Baltimore locality.
- **Rent:** HUD FY2027 Fair Market Rent for a one-bedroom.
- **Taxes:** 2026 federal brackets and FICA, plus Maryland with the Baltimore City local tax, DC and Virginia.
  Assumes a single filer taking the standard deduction.

All figures are estimates for planning, not financial advice. This isn't an official Bowie State University tool.
